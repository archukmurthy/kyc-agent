# UBO trial access

Guarded work (api/, lib/). Goal: five prospects from one company can try the UBO
module on their own, this week, without seeing the platform and without an
open-ended bill.

**If this is built badly:** a prospect sees another product's screens, one
trial user reads another's research, or a week of enthusiastic clicking
produces a surprise Anthropic invoice.

## Order, and why

1. **UBO-1 + PLAT-5** - small, and both sit in the route prospects hit hardest.
2. **Rate limits v2** - per person, daily windows, login throttling. Cost
   control has to exist before anyone is invited, not after.
3. **Invites** - codes, seats, expiry, redemption. No emails needed up front.
4. **Owner screen** - create and revoke invites without asking Claude.
5. **Product mode** - the trial deployment serves UBO and nothing else.

## Decisions already made

- Each trial user gets their own private space. No shared workspace: the demo
  has no case-list UI, so sharing would mean inventing one.
- Any email, including personal. Disposable addresses are blocked by Clerk's
  own Rules toggle - we build nothing for it.
- Seven days from first sign-in, so a link opened on day five still gives a
  full week. After that the work stays, read-only.
- Three limit layers: per person hourly, per workspace daily (alerting, high),
  hard total for trials because that one is our money.
- Refusals say which limit and when it lifts. "No result returned" reads as
  broken software.

## Tasks

1. `api/ubo-discovery.js` - take the tenant from the signed-in caller, never
   from the body, and never default it to "nium" (UBO-1). Fix the stale model
   id in `src/utils/costs.js` (PLAT-5).
2. `lib/rateLimit.js` - key on the Clerk user; drop the shared per-company
   analyst bucket; add daily and total windows; new numbers.
3. `lib/loginThrottle.js` - failed-attempt throttling on the three auth routes
   (AUTH-1).
4. `lib/uboTrials.js` + `api/ubo-invite.js` - create, redeem, list, revoke.
   Seats, expiry, per-trial budget.
5. `src/uboDemo/trial/` - redemption on landing, owner screen, "trial ended"
   and "needs an invitation" states.
6. `PRODUCT_MODE=ubo` - `src/index.js` mounts UBO only; a server guard refuses
   every non-UBO route.

## Verification

- A caller cannot file research under a tenant they do not belong to.
- The 16th research call in an hour is refused with a time, not a generic error.
- A trial that has spent its budget refuses politely and alerts us.
- Seat 6 of a 5-seat invite is refused; an expired invite is refused.
- In UBO mode, /admin and /super-admin are not found in the browser AND on the
  server.
- Full node + frontend suites and a clean build before the pull request.
