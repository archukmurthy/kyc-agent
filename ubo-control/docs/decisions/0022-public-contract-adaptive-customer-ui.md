# ADR 0022 — Public-contract adaptive customer UI

## Status

Accepted for G5.3A implementation.

## Decision

The reusable adaptive customer UI lives in the sibling `ubo-control-ui/` product area. It consumes only `ubo-journey-projection-v1`, `ubo-resolution-plan-v1`, and optionally `ubo-ownership-graph-projection-v1`.

The UI renders the customer work already selected by the headless product. It does not accept a DecisionSnapshot, InformationNeeds, Policy Pack, threshold, provider result, claim graph, or private UBO module. It does not execute Discovery, Extraction or Evidence capabilities and does not call a host API.

Customer interactions emit serializable `ubo-customer-action-v1` events containing durable bundle, work-item, action-intent and action references; canonical subject semantics; entered primitive values; confirmation/selected-option results; and presentation-only evidence handoff intents. No file or raw evidence bytes are carried.

The UI keeps only ephemeral interaction state. Submission never mutates a JourneyProjection or ResolutionPlan and never claims an InformationNeed is resolved. Authoritative state changes only after the host processes the event, records permitted facts or artifact references, asks UBO Control to re-resolve, and supplies fresh projections and a fresh plan.

```text
DecisionSnapshot
      ↓
JourneyProjection + ResolutionPlan
      ↓
Reusable Adaptive Customer Journey UI
      ↓
host-neutral customer action event
      ↓
future host processing and re-resolution
```

## Consequences

- The same component can be embedded in the current KYC product, a standalone UBO product, a demo shell, or another host.
- The graph is optional and reused through `OwnershipGraph`; graph/bundle linkage uses canonical references.
- Missing policy/product wording is visible as configuration unavailable and is never generated by an LLM.
- Evidence work is rendered as an `EVIDENCE_ACTION_REQUESTED` host intent until the separate Evidence Platform integration is approved.
- G5.3A does not change `createUboDecisionApplication`, host onboarding, APIs, dossiers, case management, or Evidence Platform.
