# Internal DecisionSnapshot v2 and history contract

Wave 7 introduces no public API. Internal callers may use `application/evaluateUboDecisionV3Review.js` only with a sealed OwnershipCase revision, schema-1.3 policy data, `runtimeMode: LAB`, an explicit evaluation time, target-bearing case context and checkpoint reference.

The result contains the exact nine immutable phase artifacts and one `ubo-decision-snapshot-v2`. Historical Wave 7 snapshots retain `ubo-requirement-resolution-v1-compat` in Phase 7. New Wave 8 snapshots pin `ubo-requirement-resolution-v2`, an `ubo-information-need-set-v2` hash, `ubo-information-need-v2` records, dependent diagnostics, separate operational blockers/reviews/specialist routes, and the private `ubo-information-needs-v2-to-plan-v1-compat` bridge. Phase 8 remains the transitional v1 compatibility planner. The pinned plan is created before the snapshot; the returned plan is the same immutable semantic artifact stored in the snapshot. Registry capability state is explicitly `NOT_PROVIDED`.

The v2 verifier dispatches Phase 7 validation by its pinned algorithm. Wave 7 content remains `TRANSITIONAL_REVIEW_ONLY`; Wave 8 content is `TRANSITIONAL_PLANNER_ONLY`. For Wave 8 it cross-checks every duplicated causal artifact against Phase 7, verifies need/set/adapter hashes, and rejects diagnostics that reference an unknown causal need.

`domain/decisionHistoryV2.js` is the internal version dispatcher. It delegates v1 snapshots to the untouched v1 verifier/reconstructor and v2 snapshots to v2 verification/reconstruction. Reconstruction returns recorded content and never calls current reasoning algorithms, provider capabilities or evidence collection. Cross-version succession requires a linear predecessor and an explicit neutral reason: `POLICY_CHANGED`, `ALGORITHM_CHANGED`, `NEW_FACTS`, `REVIEW_DECISION` or `CUSTOMER_INPUT`.

The internal `projection/ownershipGraphProjectionV2.js` may consume a Wave 8 snapshot without recalculating it. The current public `createUboDecisionApplication`, `planUboResolution`, graph/journey projections and Lab accept only their existing versions. They do not select or consume Snapshot v2 or the internal projection.
